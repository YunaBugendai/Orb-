# Security Policy

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in public issues or discussions.

Report security concerns privately through GitHub's private vulnerability reporting feature for this repository, if it is enabled. If private reporting is unavailable, contact the repository maintainer through the GitHub profile associated with this project and request a private disclosure channel.

Include:
- A concise description of the issue and its potential impact.
- The affected version, commit, or component.
- Reproduction details sufficient to verify the issue, without accessing other users' data or disrupting services.

Please allow the maintainer reasonable time to investigate and prepare a fix before public disclosure.

## Scope

This policy covers security vulnerabilities in this repository and its officially distributed artifacts. It does not authorize testing systems, accounts, or services that you do not own or have explicit permission to assess.
